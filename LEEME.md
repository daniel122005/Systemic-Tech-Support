# Cómo usar este paquete de contexto

1. Crea en el Escritorio una carpeta llamada `systemic-tech`.
2. Copia dentro el contenido de este zip (`CLAUDE.md`, `docs/`, `assets/`).
3. Mueve también dentro:
   - tu carpeta `systemic-backend` (la del backend), y
   - tu carpeta `systemic_tech_v2` renombrada como `database`.
4. En VS Code: File → Open Folder → `systemic-tech`.
5. Abre Claude Code y escribe: "Lee CLAUDE.md y los archivos de docs/ y dime qué entendiste del proyecto". Luego pídele la primera tarea del frontend.
